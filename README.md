# 🐼 Pandas Fundamentals & Data Manipulation

This repository contains my practice scripts, core concepts, and project implementations using **Pandas**—the essential library for data cleaning, manipulation, and analysis in Python.

---

## 📌 Topics Covered

* **Data Structures:** Working with 1D **Series** and 2D **DataFrames** using `pd.Series()` and `pd.DataFrame()`.
* **Data Importing & Exporting:** Reading and writing data using `pd.read_csv()`, `pd.read_excel()`, `to_csv()`, and `to_excel()`.
* **Indexing & Selection:** Filtering and slicing datasets using `.loc[]`, `.iloc[]`, boolean masking, and conditional filtering.
* **Data Cleaning & Transformation:** Handling missing values (`dropna()`, `fillna()`), removing duplicates (`drop_duplicates()`), and renaming columns (`rename()`).
* **Aggregation & Grouping:** Grouping data using `groupby()`, summarizing with `agg()`, `mean()`, `sum()`, `count()`, and creating pivot tables (`pivot_table()`).
* **Merging & Joining:** Combining datasets seamlessly using `pd.concat()`, `pd.merge()`, and join operations.

---
